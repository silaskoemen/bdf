\section{Experimental Setup and Reproducibility}\label{app:experimental-setup}

\subsection{Models}\label{app:experimental-setup-models}

\subsubsection{Regression Models}\label{app:experimental-setup-reg-models}
The regression benchmark compares BDF leaf families against probabilistic and calibrated tabular baselines. The BDF variants include conjugate Normal, Student-$t$, Poisson/Exponential, and KDE-style leaves where compatible with the target domain. Baselines include Bayesian ridge regression~\citep{bishop2006pattern}, Bayesian additive regression trees~\citep{chipman2010bart}, Gaussian processes~\citep{williams2006gaussian}, NGBoost~\citep{duan2020ngboost}, CatBoost with uncertainty, conformalized LightGBM/random-forest baselines, quantile-regression forests~\citep{meinshausen2006quantile}, Gaussian density estimation, $k$NN-KDE, and a climatological reference model used for skill scores. Exact constructor settings and tuning ranges are specified in the YAML files under \texttt{benchmarks/configs/model/}; the result artifacts record the resolved configuration used for each run.

Distributional random forests are a closely related approach for estimating conditional distributions using forests. We do not include them as a numerical baseline because the available implementations were not practically compatible with the benchmark environment; this omission is treated as a limitation rather than evidence against that method family.

\subsubsection{Classification Models}\label{app:experimental-setup-clas-models}
The classification benchmark is binary. The submitted comparison includes BDF with Beta--Bernoulli leaves, random forests, LightGBM, NGBoost, calibrated random forests, and $k$-nearest-neighbor classification. All reported classification metrics are computed from predicted probabilities for the positive class. Multiclass BDF variants based on Dirichlet--multinomial leaves are implemented in the distribution library but are outside the scope of the submitted classification experiments.

\subsection{Benchmark Protocol}\label{app:benchmark-protocol}
All real-data benchmarks use seed $1234$ and ten deterministic train/test folds. Hyperparameters are selected on fold 0 using Optuna with 50 trials and the task-appropriate proper score: CRPS for regression and log-loss for classification. The selected hyperparameters are then held fixed and evaluated on folds 1--9; tables report means and standard errors over these nine evaluation folds.

For tuning, each trial uses at most 100 training examples to keep the model-selection budget comparable across methods. Final fold evaluation uses the benchmark sample cap of 1000 observations where applicable, with larger datasets subsampled by the benchmark harness and smaller datasets evaluated at their available processed size. Search spaces are defined in \texttt{benchmarks/configs/model/*.yaml}, and each result YAML records the resolved model configuration, dataset metadata, seed, fold count, tuning metric, tuning time, and fold-level metrics.

Failed folds or mathematically undefined predictions are not silently imputed. A result file is treated as locked only when every in-scope dataset has all nine evaluation folds for the metrics used in the paper; partial GP and BART runs are therefore excluded from the main aggregate and treated as out-of-scope supplementary evidence. The final regression aggregate includes BDF, QRF, conformalized LightGBM/RF, NGBoost, CatBoost-UQ, Gaussian deep ensembles, Bayesian ridge, and $k$NN-KDE, plus a climatological reference for CRPSS normalization. The final classification aggregate includes BDF, RF, LightGBM, NGBoost, calibrated RF, and $k$NN.

\subsection{Preprocessing and Dataset Inventory}\label{app:dataset-inventory}
Datasets are processed by the repository scripts into numeric design matrices. Numeric columns are used directly, categorical columns are one-hot encoded, and rows with unresolved missing values are dropped during processing; the processed metadata records the number of samples before and after this step. Native categorical handling is not used, even for models that could support it, so all methods receive the same feature matrix. Regression targets are standardized inside each training fold for methods that require standardized targets and predictions are inverse-transformed before scoring; classification labels are encoded as binary targets with probabilities reported for the positive class.

\subsection{Regression Metrics}\label{app:computational-setup-regression-metrics}

\subsubsection{Point Metrics}

\paragraph{Mean Squared Error (MSE)}: Standard measure of average prediction error.
\begin{align}
    \text{MSE} = \frac{1}{N} \sum_{i=1}^N (y_i - \hat{y}_i)^2
\end{align}

\paragraph{Root Mean Squared Error (RMSE)}: Square root of MSE, less sensitive to outliers.
\begin{align}
    \text{RMSE} = \sqrt{\frac{1}{N} \sum_{i=1}^N (y_i - \hat{y}_i)^2}
\end{align}

\paragraph{Mean Absolute Error (MAE)}: Provides a robust measure of average prediction error, also less sensitive to outliers.
\begin{align}
    \text{MAE} = \frac{1}{N} \sum_{i=1}^N |y_i - \hat{y}_i|
\end{align}

\subsubsection{Probabilistic Metrics}

\paragraph{Negative Log-Likelihood (NLL)}: Evaluates the likelihood of observed targets under the predicted distribution.
\begin{align}
    \text{NLL} = -\frac{1}{N} \sum_{i=1}^N \log p(y_i \mid \mathbf{x}_i)
\end{align}

\paragraph{Continuous Ranked Probability Score (CRPS)}: Measures how closely the predicted cumulative distribution function aligns with the observed value.
\begin{align}
    \text{CRPS}(F, y) = \int_{-\infty}^{\infty} \big(F(z) - \mathbf{1}\{y \le z\}\big)^2 dz
\end{align}

\paragraph{Prediction Interval Coverage Accuracy (PICA):} Following \citet{koemen2026fast}, this measures the absolute deviation between desired and empirical coverage of predictive intervals.
\begin{align}
    \text{PICA}_\alpha = |\hat{c}_\alpha - \alpha|
\end{align}

\paragraph{Sharpness}: Average width of predictive intervals; narrower intervals indicate sharper predictive distributions.

\paragraph{Interval/Weighted Interval Score (IS/WIS)}: Proper scoring rules for predictive intervals; penalizes both interval width and miscoverage.
\begin{align}
    \text{IS}_\alpha = (u-l) + \frac{2}{\alpha}(l - y) \mathbf{1}\{y < l\} + \frac{2}{\alpha}(y - u) \mathbf{1}\{y > u\}
\end{align}

\subsection{Classification Metrics}\label{app:computational-setup-classification-metrics}
\paragraph{Accuracy}: Fraction of correctly classified samples.
\paragraph{F1-Score}: Harmonic mean of precision and recall, useful for imbalanced classes.


\paragraph{Log-Loss}: Measures how well predicted probabilities align with observed class labels.
\paragraph{Brier Score}: Mean squared error between predicted probabilities and one-hot encoded labels, sensitive to calibration.
\paragraph{Expected Calibration Error (ECE)}: Measures miscalibration across probability bins.
