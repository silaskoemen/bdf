\section{Experimental Setup and Reproducibility}\label{app:experimental-setup}

\subsection{Models}\label{app:experimental-setup-models}

\subsubsection{Regression Models}\label{app:experimental-setup-reg-models}
The regression benchmark compares BDF leaf families against probabilistic and calibrated tabular baselines. The BDF variants include conjugate Normal, Student-$t$, Poisson/Exponential, and KDE-style leaves where compatible with the target domain. Baselines include Bayesian ridge regression~\citep{bishop2006pattern}, Bayesian additive regression trees~\citep{chipman2010bart}, Gaussian processes~\citep{williams2006gaussian}, NGBoost~\citep{duan2020ngboost}, XGBoostLSS~\citep{marz2019xgboostlss}, CatBoost with uncertainty, conformalized LightGBM/random-forest baselines, quantile-regression forests~\citep{meinshausen2006quantile}, distributional random forests~\citep{cevid2022distributional}, Gaussian density estimation, $k$NN-KDE, and a climatological reference model used for skill scores. Exact constructor settings and tuning ranges are specified in the YAML files under \texttt{benchmarks/configs/model/}; the result artifacts record the resolved configuration used for each run.

Distributional random forests and likelihood-based distributional regression forests are closely related approaches for estimating conditional distributions using trees. We include DRF through the R \texttt{drf} package via an isolated \texttt{rpy2} worker process, because the available Python package is deprecated. XGBoostLSS is evaluated as a fused distributional-boosting baseline: Gaussian, Student-$t$, Laplace, and Gaussian-mixture variants are run under the same fold protocol and the variant selected on fold-0 tuning CRPS is used for each dataset. Variants with incomplete evaluation folds are excluded from this fused selection for that dataset. The incomplete XGBoostLSS metric vectors are: Gaussian on \texttt{yacht\_hydrodynamics} (8/9 CRPS folds), Student-$t$ on \texttt{energy\_efficiency} (8/9), Student-$t$ on \texttt{parkinsons\_updrs} (8/9), and Student-$t$ on \texttt{yacht\_hydrodynamics} (6/9). Laplace and Gaussian-mixture XGBoostLSS completed all 15 datasets with 9/9 evaluation folds.

\subsubsection{Classification Models}\label{app:experimental-setup-clas-models}
The classification benchmark is binary. The submitted comparison includes BDF with Beta--Bernoulli leaves, random forests, LightGBM, NGBoost, calibrated random forests, calibrated LightGBM, and $k$-nearest-neighbor classification. All reported classification metrics are computed from predicted probabilities for the positive class. Multiclass BDF variants based on Dirichlet--multinomial leaves are implemented in the distribution library but are outside the scope of the submitted classification experiments.

\subsection{Benchmark Protocol}\label{app:benchmark-protocol}
All real-data benchmarks use seed $1234$ and ten deterministic train/test folds. Hyperparameters are selected on fold 0 using Optuna with 50 trials and the task-appropriate proper score: CRPS for regression and log-loss for classification. The selected hyperparameters are then held fixed and evaluated on folds 1--9; tables report means and standard errors over these nine evaluation folds. For BDF, the Optuna search space includes the empirical-Bayes prior-scale hyperparameters jointly with $(\alpha,\delta,\gamma)$, $n_{\text{trees}}$, $\text{max\_depth}$, and $\text{min\_samples\_leaf}$; EB prior locations are fixed to training-fold moments (e.g.~$\mu_0 = \bar y_{\text{train}}$ for Normal--Normal). No information from folds 1--9 enters either the EB step or the Optuna objective: each trial fits BDF on a sub-split of fold 0 and scores on its complement, and the resolved configuration is then refit on fold 0 in full and frozen before fold-1--9 evaluation, ruling out leakage from held-out folds into priors or penalty parameters.

The benchmark does not cap the number of training or test observations at 100 or 1000. Those constants refer to the number of predictive draws used by sample-based probabilistic metrics: during Optuna tuning, \texttt{tuning\_sample\_size}=100 predictive samples are drawn for CRPS to keep model selection affordable; during final evaluation, \texttt{sample\_size}=1000 predictive samples are drawn for CRPS, interval scores, coverage, and PIT diagnostics when a model exposes samples rather than analytic CDFs or quantiles. Methods with native quantile outputs, such as QRF, are evaluated on their quantile grid rather than by subsampling observations. All available observations in each train/test fold are used unless a model-specific feasibility guard is explicitly triggered (e.g.~the documented GP/BART exclusions). Search spaces are defined in \texttt{benchmarks/configs/model/*.yaml}, and each result YAML records the resolved model configuration, dataset metadata, seed, fold count, tuning metric, tuning time, predictive-sample count, and fold-level metrics.

Failed folds or mathematically undefined predictions are not silently imputed. A result file is treated as locked only when every in-scope dataset has all nine evaluation folds for the metrics used in the paper; partial GP and BART runs are therefore excluded from the main aggregate and treated as out-of-scope supplementary evidence. The final regression aggregate includes BDF, QRF, DRF, fused XGBoostLSS, conformalized LightGBM/RF, NGBoost, CatBoost-UQ, Gaussian deep ensembles, Bayesian ridge, and $k$NN-KDE, plus a climatological reference for CRPSS normalization. The final classification aggregate includes BDF, RF, LightGBM, NGBoost, calibrated RF, calibrated LightGBM, and $k$NN.

Table~\ref{tab:compute-budget-selection} summarizes the model-selection budget used by the real-data and synthetic experiments. ``Per variant'' means one Optuna study per dataset and YAML model configuration. Aggregated families such as BDF-Full and XGBoostLSS are formed only after those studies finish, by choosing the variant with the best fold-0 tuning score for that dataset; fixed-regime BDF configs are used only for ablation tables and are not additional candidates in the BDF-Full aggregate.

For BDF configs that expose split-score selection, the benchmark uses a single effective categorical \texttt{score\_regime}. The regimes expand as \texttt{nle} $\mapsto$ \texttt{score\_method=nle, score\_correction=None}, \texttt{nll\_bic} $\mapsto$ \texttt{score\_method=nll, score\_correction=bic}, and \texttt{nll} $\mapsto$ \texttt{score\_method=nll, score\_correction=None}. This expansion is applied before model construction and result YAMLs store the expanded fields for compatibility with the table and plotting scripts. TPE tunes the score regime jointly with the other hyperparameters, so the fixed-regime ablation tables provide the unconfounded split-score comparison; Normal--Normal has access to \texttt{nle} because it is conjugate, whereas Student-$t$ has only \texttt{nll} and \texttt{nll\_bic}.

The synthetic DGP study uses the same ten-fold convention: fold 0 selects hyperparameters and folds 1--9 report evaluation metrics. BDF core variants are run in the default environment; QRF and DRF are run in the benchmark environment and merged as incremental result shards. DRF is evaluated through the same isolated R worker used in the real-data benchmark, and the final synthetic plots include only shards with aggregate metrics for all evaluation folds.

\subsection{Synthetic DGP Definitions}\label{app:synthetic-dgp-definitions}
The main synthetic DGP benchmark uses five one- or two-dimensional conditional distributions with known mean, variance, quantile, density, and sampler functions implemented in \texttt{benchmarks/pipeline/synthetic\_dgps.py}. All use seed $42$, ten folds with fold-0 tuning and fold-1--9 evaluation, 50 Optuna trials per model/DGP, 100 tuning predictive samples for CRPS, and 1000 final predictive samples for CRPS, central intervals, PIT diagnostics, and conditional calibration. The reported metrics include MSE against the true conditional mean, variance error when the conditional variance is finite and known, CRPS, 90\% coverage and interval score, PIT summaries, and conditional calibration/spread-skill diagnostics.

\subsection{Preprocessing and Dataset Inventory}\label{app:dataset-inventory}
Datasets are processed by the repository scripts into numeric design matrices. Numeric columns are used directly, categorical columns are one-hot encoded, and rows with unresolved missing values are dropped during processing; the processed metadata records the number of samples before and after this step. Native categorical handling is not used, even for models that could support it, so all methods receive the same feature matrix. Regression targets are standardized inside each training fold for methods that require standardized targets and predictions are inverse-transformed before scoring; classification labels are encoded as binary targets with probabilities reported for the positive class.

Target-domain labels are used to filter incompatible leaf families before fitting, but the real-valued Normal and Student-$t$ leaves remain real-valued predictive distributions even when a processed regression target is positive or count-valued. Their samples, densities, CRPS, central intervals, coverage, PIT values, and interval scores are therefore evaluated on the original target scale without truncating or renormalizing mass outside the natural support. Domain-constrained leaves such as Gamma--Poisson and Gamma--Exponential are included only for compatible target domains; if tuning selects a real-valued leaf on a positive/count dataset, the reported score reflects that explicit modeling choice rather than a support-corrected density.

\subsection{Regression Metrics}\label{app:computational-setup-regression-metrics}

\subsubsection{Point Metrics}

\paragraph{Mean Squared Error (MSE)}: Standard measure of average prediction error.
\begin{align}
    \text{MSE} = \frac{1}{N} \sum_{i=1}^N (y_i - \hat{y}_i)^2
\end{align}

\paragraph{Root Mean Squared Error (RMSE)}: Square root of MSE, in the target's original units and more sensitive to large errors than MAE.
\begin{align}
    \text{RMSE} = \sqrt{\frac{1}{N} \sum_{i=1}^N (y_i - \hat{y}_i)^2}
\end{align}

\paragraph{Mean Absolute Error (MAE)}: Provides a robust measure of average prediction error, also less sensitive to outliers.
\begin{align}
    \text{MAE} = \frac{1}{N} \sum_{i=1}^N |y_i - \hat{y}_i|
\end{align}

\subsubsection{Probabilistic Metrics}

\paragraph{Negative Log-Likelihood (NLL)}: Evaluates the likelihood of observed targets under the predicted distribution.
\begin{align}
    \text{NLL} = -\frac{1}{N} \sum_{i=1}^N \log p(y_i \mid \mathbf{x}_i)
\end{align}

\paragraph{Continuous Ranked Probability Score (CRPS)}: Measures how closely the predicted cumulative distribution function aligns with the observed value.
\begin{align}
    \text{CRPS}(F, y) = \int_{-\infty}^{\infty} \big(F(z) - \mathbf{1}\{y \le z\}\big)^2 dz
\end{align}

\paragraph{Prediction Interval Coverage Accuracy (PICA):} Following \citet{koemen2026fast}, this measures the absolute deviation between desired and empirical coverage of predictive intervals.
\begin{align}
    \text{PICA}_\alpha = |\hat{c}_\alpha - \alpha|
\end{align}

\paragraph{Sharpness}: Average width of predictive intervals; narrower intervals indicate sharper predictive distributions.

\paragraph{Interval/Weighted Interval Score (IS/WIS)}: Proper scoring rules for predictive intervals; penalizes both interval width and miscoverage.
\begin{align}
    \text{IS}_\alpha = (u-l) + \frac{2}{\alpha}(l - y) \mathbf{1}\{y < l\} + \frac{2}{\alpha}(y - u) \mathbf{1}\{y > u\}
\end{align}

\subsection{Classification Metrics}\label{app:computational-setup-classification-metrics}
\paragraph{Accuracy}: Fraction of correctly classified samples.
\paragraph{F1-Score}: Harmonic mean of precision and recall, useful for imbalanced classes.


\paragraph{Log-Loss}: Measures how well predicted probabilities align with observed class labels.
\paragraph{Brier Score}: Mean squared error between predicted probabilities and one-hot encoded labels, sensitive to calibration.
\paragraph{Expected Calibration Error (ECE)}: Measures miscalibration across probability bins.
