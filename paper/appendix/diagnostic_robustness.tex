\subsection{Conditional calibration by predicted uncertainty}\label{app:conditional-diagnostics}

Marginal coverage can hide failures that occur only in low- or high-uncertainty regions. To check whether the regression intervals remain calibrated locally, we recompute evaluation predictions using the stored best hyperparameters and bin test points by each method's predicted interquartile range (IQR). Within each decile we report empirical 90\% coverage, 90\% interval score, and CRPS.

\input{tables/conditional_diagnostics/conditional_diagnostics_summary.tex}
